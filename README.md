# VoiceCapture для Windows

Голосовой ввод в любое поле: **зажал правый Ctrl → говоришь → отпустил → текст вставился там, где курсор.**
Всё распознаётся на твоём ноутбуке, интернет нужен только один раз — скачать модель.

Это Windows-версия идеи [VoiceCapture для macOS](https://github.com/oiv-an/voice-capture-mac) (v3.6.0):
тот же движок **GigaAM v3 E2E RNNT** (русский, сам ставит запятые, точки и заглавные),
тот же фильтр «э-э / эээ / а-а-а / эм / ммм» из версии 3.6.1.

## Установка (самое простое)

1. Скачай и распакуй архив (кнопка **Code → Download ZIP** на странице репозитория).
2. Двойной клик по **`install.bat`**. Админ-права не нужны.
3. Подожди 2–5 минут (скачивается Python и модель ~400 МБ). В конце прозвучат два коротких сигнала — готово.

Или одной строкой в PowerShell (скачает, поставит, запустит):

```powershell
irm https://raw.githubusercontent.com/AlexTrader2278/voice-capture-win/main/bootstrap.ps1 | iex
```

## Как пользоваться

| Действие | Что сделать |
|---|---|
| Продиктовать | Курсор в поле → **зажать правый Ctrl**, говорить, отпустить |
| Выйти из программы | Ctrl + Alt + Shift + G |

Сигналы: высокий короткий — запись пошла; низкий короткий — отпустил, распознаю; двойной высокий — текст вставлен; длинный низкий — пусто или ошибка.
Совет: зажал → полсекунды пауза → говори (микрофон открывается не мгновенно).

Запускается сама при входе в Windows. Убрать — `uninstall.bat`.

## Требования

- Windows 10/11, **обычный Intel/AMD-ноутбук (64 бит)**. ARM-ноутбуки (Snapdragon) не поддерживаются.
- ~2 ГБ свободного места, интернет на время установки.
- Микрофон. Если не пишет: *Параметры → Конфиденциальность → Микрофон → разрешить классическим приложениям*.

## Настройки — `%LOCALAPPDATA%\VoiceCapture\config.json`

| Ключ | Смысл |
|---|---|
| `mode` | `hold` — держать клавишу; `toggle` — нажал/нажал (для длинной диктовки) |
| `hotkey` | клавиша: `right ctrl`, `right alt`, `f9`, `pause` … |
| `remove_fillers` | `true` — вырезать «э-э», «эм», «ммм» |
| `max_seconds` | авто-стоп записи (по умолчанию 120 с) |
| `input_device` | `null` — микрофон по умолчанию, либо номер из `voice-input.bat --list-devices` |
| `restore_clipboard` | вернуть прежнее содержимое буфера после вставки |

После правки — выйти (Ctrl+Alt+Shift+G) и запустить снова через ярлык/`run-hidden.vbs`.

## Чем отличается от macOS-версии

| Есть | Нет (пока) |
|---|---|
| Локальный GigaAM v3 с пунктуацией | Перевод на лету (⌥) |
| Фильтр «э-э», «эм» | Список дел и плавающая шайба (⇧) |
| Hold-to-talk, автовставка | Окно настроек (правится `config.json`) |
| Автозапуск | Live-текст во время записи; запись длиннее 120 с (лимит настраивается) |

## Проблемы

- **Ничего не вставляется в терминале/консоли** — там вставка не по Ctrl+V; в браузерах, Word, мессенджерах работает.
- **Антивирус ругается на `keyboard`** — библиотека перехватывает клавиши, это нужно для хоткея; код открыт в `voice_input.py`.
- **Диагностика** — запустить `%LOCALAPPDATA%\VoiceCapture\voice-input.bat --diag`, лог рядом: `voice-input.log`.
- **Не скачалась модель** — нужен доступ к huggingface.co (в РФ иногда нужен VPN на время установки). Повторить `install.bat`.
