# Как подготовить Manus на Windows-ноуте, чтобы он смог поставить VoiceCapture

Важно: обычный Manus в браузере работает в облачной песочнице и ничего не может поставить на ваш ноутбук. Нужно **десктоп-приложение Manus с режимом «My Computer»** (Windows 10/11).

1. Откройте официальный сайт Manus (manus.im) → раздел **Download / Desktop**. Скачайте установщик для Windows (.exe) или поставьте из Microsoft Store.
2. Установите и войдите в аккаунт Manus.
3. Создайте папку `C:\ManusWorkspace`. В приложении откройте вкладку **My Computer** → **Add Folder** → выберите эту папку → подтвердите запрос Windows.
4. Вставьте промпт из `MANUS_PROMPT.md`. Когда Manus спросит разрешение на запуск команд — выбирайте **Allow Once** (разрешить один раз) на каждой команде установки.
5. Дождитесь «=== ГОТОВО ===» и двух коротких сигналов.

Если Manus не стартует или не даёт доступ — запасной путь: скачать ZIP репозитория (Code → Download ZIP), распаковать, дважды щёлкнуть `install.bat`.
